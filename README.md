
# Event System RFC

WIP demo application using ts-event-bus 

## Installation

To get started, clone the repository and install dependencies:

```bash
git clone https://github.com/codeHendrix/event-system-rfc.git
cd event-system-rfc
npm install
```

## Usage

Run the app in development mode:

```bash
pnpm run dev
```
